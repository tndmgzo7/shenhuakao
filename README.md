# 中国神话体系考（清代以前）

本项目致力于对清代以前的中国神话体系进行穷尽式、系统性的考据与知识库梳理，可用于学术研究、数字人文以及艺术创作。

## 资料结构与断代划分

- **断代下限**：1644 年（明亡）。
- **包含范围**：
  - 先秦、山海经全条目与古图对勘
  - 汉魏六朝、唐五代、宋辽金、元代考据
  - 明代神怪与仙真考据
  - 道教神谱、真灵位业图、历代精怪图谱（白泽精怪图、三才图会、蒋应镐本山海经、胡文焕本等）
- **核心数据格式**：
  - 各朝代全条目汇总：`.md`（全文阅览）、`.csv`（结构化数据）、`.xlsx`（表格检索）
  - 图像索引与逐图裁图：`images/crops/` 及对应挂图表、置信度考释

## 目录索引

- `定稿版/`：**【权威定稿库】** 包含先秦至明代（00~11及99清单）全时期已校对定稿数据表（Markdown、CSV、Excel全格式）
- `神话考_截至元代_2026-10-13.zip/`：先秦至元代条目库、挂图表及图像素材库（含古籍插图裁图）
- `神话考_明代/`：明代全条目、书目、排除与存疑清单及明代图谱素材
